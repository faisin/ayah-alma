AYAH ALMA - SSH SSL-ONLY

Mode: TLS/SSL langsung, tanpa WebSocket dan tanpa HTTP payload.
Host: domain layanan
Port: 444/TCP
Username/password: akun SSH biasa

Alur: client TLS -> Nginx Stream TCP 444 -> stunnel TLS 127.0.0.1:2222 -> OpenSSH 127.0.0.1:22.
Port 443 tetap digunakan oleh Nginx HTTPS dan rute tunneling yang sudah ada.

Penting: buka TCP 444 pada firewall sistem operasi dan firewall/security list Oracle Cloud.
Jangan mengisi path WebSocket atau payload pada profil SSL-only.
Sertifikat Let's Encrypt diperpanjang melalui acme.sh; hook akan memulai ulang layanan ayah-ssh-ssl.
